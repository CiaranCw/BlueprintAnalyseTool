# .agent/archive

Cold storage for superseded/obsolete material: retired designs, deprecated approaches, expired tasks,
outdated conclusions, old plan drafts. **Not** read by default — only when tracing why something was
dropped or reproducing an old decision.

When a `domains/*.md` or `DECISIONS.md` conclusion becomes outdated: update the current file with the new
conclusion, and move the old content here (dated), e.g. `archive/2026-07-10-old-<topic>.md`.

(Currently empty — nothing archived yet.)
